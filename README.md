# Hotel-Kashyyk-project
A group project for college, made with two other classmates, where the program runs a management system for a theoretical hotel, and can have guests sign into their rooms, book a dinner table, and checkout with a calculated sum for their bill.
Through the making of this project, I got to learn more about the programming language C, strengthened my programming skills, practised my teamwork, communication and organisation, and had experience with working with the procedural programming paradigm.
